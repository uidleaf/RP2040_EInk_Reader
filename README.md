# RP2040 墨水屏阅读器 (E-Ink Reader)

这是一个基于 Raspberry Pi RP2040 芯片和 2.9 寸微雪电子（V1兼容，如 HINK-E029A01）墨水屏驱动的掌上电子书阅读器固件项目。它支持从 SD 卡读取并渲染含有中文字符的 TXT 小说，同时提供极致的防丢键按钮响应，以及 USB HID 模拟键盘功能。

## ✨ 核心特性

- **完整中文字库与标点系统**
  - 内置了高达 6800 余字的完整中文 GB2312 点阵字库，阅读体验媲美原生。
  - **超强符号扩展**：深度扩充了 435 种中日韩 (CJK) 全角标点符号、通用排版标点及特殊符号，从《》【】到各种特殊括号，完美消除乱码与问号，实现沉浸式排版！

- **自适应极速刷新 (Fast Refresh)**
  - 针对微雪 2.9" 墨水屏 V1 版本定制的 LUT 表，支持阅读时局部快速刷新。
  - 预设为“5页局刷+1次全刷”的混合刷新策略，既保证了快速翻页的速度，又彻底消除了屏幕残影和重影。

- **超高灵敏度按键（无缝防丢键）**
  - 采用了 **硬件定时器 (Hardware Timer)** + **事件缓冲队列 (Event Queue)** 架构。
  - 墨水屏在长达一秒的刷新阻塞期内，底层仍能精准捕获用户的每一次连续短按操作，并存入队列，刷新后自动连翻，实现**零吞键**。
  - 短按：确认 / 下一页 | 双击：下一项 | 长按：返回 / 退出。

- **动态内存与大文件索引**
  - 采用独创的 `.idx` 分页索引文件机制，支持秒开高达 5MB 以上、数百万字的超大 TXT 文件，告别“内存溢出”无法打开的尴尬。
  - 完美支持长文件名展示和动态文件浏览器过滤。

- **模拟键盘特性 (USB HID Keyboard)**
  - 当你在设置菜单选择不同的 `.json` 键值配置文件时，它能作为一台免驱的 USB HID 键盘设备输出内容。
  - 非常适合用于工作时的自动化脚本文本输出，或者作为一个微型可编程键盘使用。
  - 阅读模式下安全挂起大容量存储通讯（MSC_Disk），避免文件损坏。

## 📂 文件结构与说明

本项目中的代码均已添加详细的中文注释，方便阅读和二次开发：
- `main.c`: 主程序入口，包含硬件定时器轮询和按键事件防丢队列逻辑。
- `ui.c` / `ui.h`: 图形化界面绘制系统，管理主菜单、设置、文件管理器以及小说阅读和进度保存功能。
- `EPD_2in9.c`: 墨水屏的底层 SPI 通信与 LUT 驱动表（包含局部和全局刷新命令）。
- `font_gb2312.c`: 1.5MB 庞大体积的中文字库，并包含手工注入的 435 个完美版中文全角符号矩阵。
- `msc_disk.c`: TinyUSB Mass Storage 类配置，负责开机按键映射进入 U盘模式。
- `usb_descriptors.c`: HID/MSC 双模设备描述符。

## 🚀 编译指南

本项目依赖于 Pico C/C++ SDK，以及集成化的 FATFS 和 TinyUSB 库：
1. 确保已安装 CMake 和 Pico SDK 工具链。
2. 创建 `build` 文件夹并进入。
3. 执行 `cmake ..` 然后 `cmake --build .`。
4. 将生成的 `eink_reader.uf2` 拖入进入 BOOTSEL 模式的树莓派 RP2040 存储盘即可。
