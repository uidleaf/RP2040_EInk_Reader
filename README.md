# RP2040 墨水屏阅读器 (E-Ink Reader)

这是一个基于 Raspberry Pi RP2040 芯片和 2.9 寸微雪电子（V1兼容，如 HINK-E029A01）墨水屏驱动的掌上电子书阅读器固件项目。它支持从 SD 卡读取并渲染含有中文字符的 TXT 小说，同时提供极致的防丢键按钮响应，以及 USB HID 模拟键盘功能。硬件使用嘉立创eda进行开发。

## ✨ 核心特性

- **完整中文字库与标点系统**
  - 内置了高达 6800 余字的完整中文 GB2312 点阵字库，阅读体验媲美原生。
  - **超强符号扩展**：深度扩充了 435 种全角标点符号、通用排版标点及特殊符号，从《》【】到各种特殊括号，完美消除乱码与问号，实现沉浸式排版！

- **自适应极速刷新 (Fast Refresh)**
  - 针对微雪 2.9" 墨水屏 V1 版本定制的 LUT 表，支持阅读时局部快速刷新。
  - 预设为“5页局刷+1次全刷”的混合刷新策略，既保证了快速翻页的速度，又彻底消除了屏幕残影和重影。

- **超高灵敏度按键（无缝防丢键）**
  - 采用了 **硬件定时器 (Hardware Timer)** + **事件缓冲队列 (Event Queue)** 架构。
  - 墨水屏在长达一秒的刷新阻塞期内，底层仍能精准捕获用户的每一次连续短按操作，并存入队列，刷新后自动连翻，实现**零吞键**。
  - 短按：确认 / 下一页 | 双击：下一项 | 长按：返回 / 退出。

- **动态内存与大文件索引**
  - 采用独创的 `.idx` 分页索引文件机制，支持秒开高达 5MB 以上、数百万字的超大 TXT 文件，告别“内存溢出”无法打开的尴尬。
  - 完美支持长文件名展示和动态文件浏览器过滤。

- **双重 U 盘架构与内存态虚拟 Flash (全新特性)**
  - **传书模式**：按住按钮开机，暴露真实的 SD 卡供电脑读写。
  - **阅读模式**：直接开机，单片机将**彻底隐藏真实 SD 卡**（防止系统抢占损坏），并使用 C 语言在底层拦截 SCSI 协议，**直接在内存中凭空捏造出一个 16KB 的纯净虚拟 U 盘 (FAT12)**。
  - **0 延迟挂载**：虚拟 U 盘全在 RAM 中运作，挂载速度无限接近 0 毫秒，告别物理 SD 卡插入时的漫长扫描与初始化等待。

- **究极极客宏键盘 (HID 注入分离与加速)**
  - **触发与执行解耦**：在 SD 卡创建 `pc-cmd` 文件夹存放墨水屏显示的触发 JSON；在 `pc-bat` 文件夹存放**纯文本**执行脚本。
  - **多文件动态映射**：开机时自动扫描 `pc-bat`，无需任何转义大括号，直接将纯文本转为虚拟 U 盘里的原生 `.bat` 批处理文件（并深度篡改 FAT 的 NTRes 标志，完美还原小写文件名）。
  - **光速触发优化**：重写了 TinyUSB 的底层 `usb_descriptors.c`，强制将 HID Polling Interval 压榨到极致的 `1ms`，并修改了 VID 绕过 Windows 的驱动缓存，配合几十个字符的最短盲搜 U 盘命令，将长代码的触发时间从 6 秒压缩至 1 秒以内！

## 📂 文件结构与说明

本项目中的代码均已添加详细的中文注释，方便阅读和二次开发：
- `main.c`: 主程序入口，包含硬件定时器轮询、JSON触发指令解析与虚拟 U 盘文件动态构建系统。
- `ui.c` / `ui.h`: 图形化界面绘制系统，管理主菜单、设置、文件管理器以及小说阅读和进度保存功能。
- `EPD_2in9.c`: 墨水屏的底层 SPI 通信与 LUT 驱动表（包含局部和全局刷新命令）。
- `font_gb2312.c`: 1.5MB 庞大体积的中文字库，并包含手工注入的 435 个完美版中文全角符号矩阵。
- `msc_disk.c`: TinyUSB Mass Storage 核心逻辑，重写 `tud_msc_read10_cb` 实现了纯内存态 FAT12 虚拟 U 盘。
- `usb_descriptors.c`: HID/MSC 双模设备描述符，已调教为极致 1ms 轮询率。

## 🚀 编译指南

本项目依赖于 Pico C/C++ SDK，以及集成化的 FATFS 和 TinyUSB 库：
1. 确保已安装 CMake 和 Pico SDK 工具链。
2. 创建 `build` 文件夹并进入。
3. 执行 `cmake ..` 然后 `cmake --build .`。
4. 将生成的 `eink_reader.uf2` 拖入进入 BOOTSEL 模式的树莓派 RP2040 存储盘即可。
